# Biomedical Data Analysis — Week 1

## Overview

This project demonstrates a basic data science workflow using a publicly available diabetes dataset.

The main objectives were to:

* Acquire a public dataset
* Inspect the dataset
* Identify missing and invalid values
* Check for duplicate records
* Correct data issues
* Perform preprocessing
* Conduct exploratory data analysis (EDA)
* Create data visualizations
* Identify important patterns and relationships

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* GitHub

## Dataset

The dataset contains clinical variables related to diabetes analysis, including variables such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age
* Diabetes Outcome

The original dataset source is documented in the project report.

## Data Cleaning

The following checks were performed:

* Missing-value analysis
* Duplicate-record detection
* Data-type inspection
* Identification of potentially invalid zero values
* Missing-value treatment
* Validation of numerical variables

The cleaning decisions were documented in the Jupyter Notebook and final report.

## Exploratory Data Analysis

The analysis included:

* Descriptive statistics
* Glucose distribution
* Diabetes outcome distribution
* Glucose comparison between outcome groups
* BMI and glucose relationship
* Correlation analysis

## Visualizations
